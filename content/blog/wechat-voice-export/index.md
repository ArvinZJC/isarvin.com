A mate wanted to keep some WeChat voice messages as ordinary audio files and asked me to help. It sounded like a small conversion job: find the files, turn them into MP3s, and give them sensible names.

Finding the audio took more work than converting it. The Mac could have a message's timestamp and other details without having the recording itself, and the files that looked promising at first weren't usable SILK audio.

I ended up writing a Python script to read the recordings from WeChat's local databases. It can export what's on the Mac; it can't recover audio that never made it there.

### Looking for the recordings

I started with a saved collection and some `.silk_temp` files. The decoder rejected those files as invalid SILK v3 data, so that route went nowhere.

What worked was reading `VoiceInfo.voice_data` from the local `media_*.db` databases. I could then match those audio bytes to the timestamps and IDs in the chat records.

The script therefore works with local chat and media records. It doesn't extract resources held only in Favourites, copy messages from a phone or record playback.

> [!NOTE]
>
> I used WeChat 4.1.15 on macOS, Python 3.14 and `pilk` 0.2.4. The code requires Python 3.10 or later, SQLCipher and FFmpeg/ffprobe. Other WeChat versions may need changes to the database queries or key-capture helper.

### Reading the databases

On my Mac, the account directories were under:

```text
~/Library/Containers/com.tencent.xinWeChat/Data/Documents/xwechat_files/
  <account>/db_storage/
    contact/contact.db
    message/message_0.db
    message/media_0.db
    ...
```

I scan only `contact.db` and numbered `message_N.db` / `media_N.db` files. The numeric suffix check excludes other databases with similar names.

These are encrypted databases. Python's ordinary `sqlite3.connect()` cannot open them with a SQLCipher key. My small reader loads Homebrew's `libsqlcipher.dylib` through `ctypes`, opens each file with `SQLITE_OPEN_READONLY`, supplies the raw key through `sqlite3_key`, selects SQLCipher 4 compatibility and enables `query_only`. A query against `sqlite_master` checks that the key actually works.

The reader returns query results as dictionaries. Its C callback receives text, so I request `hex(voice_data)` when retrieving a BLOB and convert it back with `bytes.fromhex()`. That avoids accidentally treating binary audio as a NUL-terminated text string.

The [complete script](#complete-example) is at the end of the post, including the SQLCipher reader and its MIT notice. I'll go through the queries and conversion code first.

### Matching messages to audio

I use the contact database to resolve a name to a username, look up that conversation in the message databases, then find the corresponding audio in the media databases.

Each message database has its own `Name2Id` mapping. Reusing a numeric sender ID from another database can point to the wrong person, so the lookup must happen in the same database as the message. Audio matching also needs both the conversation and the server message ID.

In this schema, a conversation's message table is named `Msg_` followed by the MD5 digest of its username. I generate that name and query each message database:

```python
import hashlib

table = "Msg_" + hashlib.md5(username.encode("utf-8")).hexdigest()
message_sql = f"""
SELECT m.local_id, m.server_id, m.create_time,
       n.user_name AS sender
FROM {table} AS m
LEFT JOIN Name2Id AS n ON n.rowid = m.real_sender_id
WHERE (m.local_type & 4294967295) = 34
"""
```

The low 32 bits of `local_type` identify a voice message as `34` in this layout. The table name is generated from a fixed prefix and a hexadecimal digest, rather than interpolated from an arbitrary SQL identifier. I check `sqlite_master` before querying because a particular conversation need not appear in every shard.

The media lookup runs separately in **each media shard**, using that shard's own name mapping:

```sql
SELECT v.rowid AS media_rowid, v.svr_id,
       length(v.voice_data) AS bytes
FROM VoiceInfo AS v
JOIN Name2Id AS n ON n.rowid = v.chat_name_id
WHERE n.user_name = :username;
```

`:username` denotes the resolved contact identifier. In the C-API wrapper included below, which exposes `sqlite3_exec` rather than bound statements, the caller uses a SQL string-literal helper that doubles single quotes. A Python DB-API implementation could bind this value instead.

I collect candidate rows by server ID after filtering them to the selected conversation. The core of that join is:

```python
from collections import defaultdict


def match_audio(messages, media_rows):
    # media_rows already belong to this conversation, across all media shards.
    candidates = defaultdict(list)
    for row in media_rows:
        sid = str(row["svr_id"] or "0")
        if sid != "0" and int(row["bytes"] or 0) > 0:
            candidates[sid].append(row)

    for message in messages:
        matches = candidates.get(str(message["server_id"] or "0"), [])
        status = ("available" if len(matches) == 1 else
                  "not_local" if not matches else "ambiguous_audio")
        yield {**message, "status": status,
               "audio": matches[0] if len(matches) == 1 else None}
```

This short version shows the matching rule. The exporter also carries the source shard and media row ID, deduplicates message records by non-zero server ID, and stops if duplicate message records disagree about timestamp or direction. A zero server ID cannot identify an audio match. For the default received-only filter, a message counts as received only when its resolved sender equals the contact's username; an unresolved sender is not guessed.

Each record gets one of these statuses:

| Status | Meaning |
| --- | --- |
| `available` | Exactly one non-empty local audio row matched the message. |
| `not_local` | No matching non-empty audio row was found. |
| `ambiguous_audio` | More than one candidate matched; export skips it. |
| `exported` | Conversion and the output checks completed for that record. |

An `available` record still needs checking when it's exported. The script reads the bytes again and checks their size and SILK header before decoding; changed or invalid data causes an error.

### Database keys and live files

Listing and export use SQLCipher in read-only mode, without restarting WeChat or requesting a database checkpoint. Recent records may still be in SQLite's write-ahead log (WAL), so copying just the live `.db` file can miss them. I read the database in place, with its sidecar files, and let SQLite handle the WAL.

The SQLCipher reader and capture helper are adapted from [acmerfight's macOS WeChat toolkit](https://gist.github.com/acmerfight/0a01249ef72970d07a2603dbb629e80f). I retained the MIT attribution and narrowed the helpers to contact, message and media databases, with a separate wrapper for temporary capture and cleanup.

Working keys can be reused. To obtain missing keys or replace invalid ones, I use a helper that requires native Apple Silicon macOS and Xcode Command Line Tools, with WeChat quit normally beforehand. It creates a temporary app copy, re-signs that copy and runs it under LLDB. Candidates are checked against database-page HMACs and real read-only SQLCipher queries before they are saved.

This leaves the installed app and SIP unchanged, but the temporary copy still uses the real account's data. WeChat may update its caches or login state. I save drafts before quitting and avoid writing messages in the temporary copy.

### Running the example

You'll need **existing, verified keys** to run the example below. Key capture isn't included in it; the public toolkit linked above documents the setup I adapted.

In that helper, the database's first 16 bytes identify its salt. On the tested arm64 build, an LLDB breakpoint on `CCKeyDerivationPBKDF` lets the helper inspect derivations for those selected salts. It recognises the SHA-512 derivation with 256,000 rounds, and the two-round derivation used for the page HMAC key. I check each candidate against the first-page HMAC, then try a SQLCipher read before saving it. These checks depend on the WeChat and SQLCipher versions used here.

Put the verified database keys in a private JSON file. The reader accepts entries indexed by relative database path or salt. For the path format, replace each placeholder below with that database's 64-character hexadecimal key:

```json
{
  "keys": {
    "contact/contact.db": {"enc_key": "<64 hexadecimal characters>"},
    "message/message_0.db": {"enc_key": "<64 hexadecimal characters>"},
    "message/media_0.db": {"enc_key": "<64 hexadecimal characters>"}
  }
}
```

Include an entry for every numbered message and media database being scanned, not just shard zero. The loader rejects an ambiguous match and checks that the manifest has no group or other permissions. The key enters the C API in memory; it is not passed as a shell argument or printed in an error.

### List before exporting

I check the listing before exporting: the contact, message times, direction and available audio should all look right.

A nickname or remark may match more than one contact, so the script stops if it can't resolve a unique username. It also requires a database root, which avoids picking the wrong account on a Mac with several logins.

It lists received voice messages by default. You can select sent messages or both directions, but group chats aren't supported.

Date filtering uses `Asia/Shanghai` by default. Both boundary dates are inclusive: internally, the upper bound is midnight at the start of the following day. Using an explicit timezone keeps a message near midnight from moving unexpectedly between dates when the script runs in another environment.

Only after checking that listing do I export to a new directory. The script refuses an existing output path, even an empty directory. That makes retries a little less convenient, but avoids mixing a partial attempt with a fresh export or overwriting an earlier result.

### Converting SILK to MP3

The conversion path is SILK → PCM → MP3. `pilk` decodes at 24 kHz, and FFmpeg reads the intermediate PCM as mono, signed 16-bit little-endian audio before encoding it with `libmp3lame`.

The extraction step rechecks the selected row's conversation and server ID as well as its row ID. After `bytes.fromhex()`, it requires the same byte count observed during listing and one of the two recognised headers: `b"#!SILK_V3"` or `b"\x02#!SILK_V3"`. Merely finding a non-empty BLOB is not sufficient.

Here's the conversion function on its own. It takes SILK bytes and an output path, refuses to overwrite files, and returns the durations and hashes for the manifest:

```python
import hashlib
import json
import subprocess
import tempfile
from pathlib import Path

import pilk


def convert_voice(data, destination):
    if not data.startswith((b"#!SILK_V3", b"\x02#!SILK_V3")):
        raise ValueError("Not recognised SILK audio")
    destination = Path(destination)
    if destination.exists():
        raise FileExistsError(destination)

    with tempfile.TemporaryDirectory(prefix="voice-convert-") as folder:
        silk = Path(folder) / "voice.silk"
        pcm = Path(folder) / "voice.pcm"
        silk.write_bytes(data)
        pilk.decode(str(silk), str(pcm), pcm_rate=24000)
        size = pcm.stat().st_size
        if size == 0 or size % 2:
            raise ValueError("Empty or incomplete 16-bit PCM")
        decoded_seconds = size / (24000 * 1 * 2)
        subprocess.run([
            "ffmpeg", "-v", "error", "-nostdin", "-n",
            "-f", "s16le", "-ar", "24000", "-ac", "1",
            "-i", str(pcm), "-c:a", "libmp3lame", "-q:a", "2",
            str(destination),
        ], check=True)

    subprocess.run([
        "ffmpeg", "-v", "error", "-nostdin", "-i", str(destination),
        "-f", "null", "-",
    ], check=True)
    probe = json.loads(subprocess.check_output([
        "ffprobe", "-v", "error", "-show_entries",
        "format=duration:stream=codec_name", "-of", "json",
        str(destination),
    ], text=True))
    if not probe["streams"] or probe["streams"][0]["codec_name"] != "mp3":
        raise ValueError("Output is not MP3")
    seconds = float(probe["format"]["duration"])
    if abs(seconds - decoded_seconds) > 0.25:
        raise ValueError("Unexpected duration change")
    return {
        "decoded_seconds": decoded_seconds,
        "mp3_seconds": seconds,
        "silk_sha256": hashlib.sha256(data).hexdigest(),
        "mp3_sha256": hashlib.sha256(destination.read_bytes()).hexdigest(),
    }
```

At 24,000 samples per second, one channel and two bytes per sample, the PCM uses 48,000 bytes per second; dividing its size by that gives the duration. FFmpeg's `-n` flag refuses an existing output even if it appeared after the Python existence check.

After encoding, I decode the whole MP3 with FFmpeg and use ffprobe to check its codec and duration. A difference of more than 0.25 seconds from the PCM duration fails the check. This catches conversion problems, though I'd still listen to recordings that matter.

Filenames use the original message timestamp: `YYYY-MM-DD_HH-MM-SS.mp3`. I count the available messages per second before exporting and append the server message ID wherever timestamps collide. Temporary PCM is deleted automatically. The optional SILK copy keeps the original bytes, since MP3 is lossy.

The JSON and CSV manifests record identifiers, timestamps, source databases, durations, hashes and statuses. Missing or ambiguous audio remains visible there instead of disappearing from the totals.

After each successful conversion, I add the record to the JSON manifest, write it to a temporary file in the output directory and use `os.replace()` to replace the previous version. This avoids leaving half-written JSON if a write is interrupted. The audio files and final CSV are still written separately.

If export fails part-way through, the JSON manifest contains the records processed so far. It may omit the failed record and everything after it, and the CSV may not exist yet. Fix the cause and retry into a new directory; the presence of some MP3s doesn't mean the whole job finished.

### Keys, cleanup and testing

I keep keys in a `.local/` directory with mode `0700`, and `keys.json` has mode `0600`. The example below lets you choose the location with `--key-file`. Take care when copying the working folder: the keys can go with it. I keep them, the manifests and the recordings out of version control.

My key-capture wrapper removes the temporary app after completion, an ordinary error or a handled cancellation. A crash or forced termination can leave it behind, so I also have a cleanup helper for marked capture directories. It refuses to remove a temporary app that's still running.

I tested the implementation with synthetic encrypted databases and synthetic audio. The cases cover sender mappings, ambiguous contacts, missing or duplicate media, actual SILK-to-MP3 conversion and the key-refresh helper's cleanup behaviour. That lets me exercise awkward cases without turning my mate's recordings into test fixtures.

The script gives me both the audio files and a list of what it couldn't export. That second part matters: otherwise, a missing recording is easy to overlook amongst the MP3s.

import ctypes as C
import ctypes.util
import json
import os
from pathlib import Path
import re


def library():
    candidates = [os.environ.get('SQLCIPHER_LIBRARY'),
                  '/opt/homebrew/opt/sqlcipher/lib/libsqlcipher.dylib',
                  '/usr/local/opt/sqlcipher/lib/libsqlcipher.dylib',
                  ctypes.util.find_library('sqlcipher')]
    name = next((x for x in candidates if x and (not x.startswith('/') or Path(x).exists())), None)
    if not name:
        raise RuntimeError('SQLCipher library missing; install with brew install sqlcipher')
    lib = C.CDLL(name)
    lib.sqlite3_open_v2.argtypes = [C.c_char_p, C.POINTER(C.c_void_p), C.c_int, C.c_char_p]
    lib.sqlite3_open_v2.restype = C.c_int
    lib.sqlite3_close.argtypes = [C.c_void_p]
    lib.sqlite3_key.argtypes = [C.c_void_p, C.c_void_p, C.c_int]
    lib.sqlite3_key.restype = C.c_int
    lib.sqlite3_exec.argtypes = [C.c_void_p, C.c_char_p, C.c_void_p, C.c_void_p, C.c_void_p]
    lib.sqlite3_exec.restype = C.c_int
    lib.sqlite3_busy_timeout.argtypes = [C.c_void_p, C.c_int]
    return lib


class DB:
    def __init__(self, path, key):
        if not re.fullmatch(r'[0-9a-fA-F]{64}', key):
            raise ValueError('expected 64 hex characters for raw SQLCipher key')
        self.lib = library()
        self.ptr = C.c_void_p()
        flags = 1  # SQLITE_OPEN_READONLY
        rc = self.lib.sqlite3_open_v2(os.fsencode(path), C.byref(self.ptr), flags, None)
        if rc:
            self.close()
            raise RuntimeError(f'SQLCipher open failed (code {rc})')
        try:
            key_arg = ("x'" + key + "'").encode('ascii')
            rc = self.lib.sqlite3_key(self.ptr, key_arg, len(key_arg))
            if rc:
                raise RuntimeError(f'SQLCipher key setup failed (code {rc})')
            self.query('PRAGMA cipher_compatibility=4;')
            self.lib.sqlite3_busy_timeout(self.ptr, 2000)
            self.query('PRAGMA query_only=ON;')
            self.query('SELECT count(*) FROM sqlite_master;')
        except BaseException:
            self.close()
            raise

    def query(self, sql):
        rows = []
        callback_type = C.CFUNCTYPE(C.c_int, C.c_void_p, C.c_int,
                                   C.POINTER(C.c_char_p), C.POINTER(C.c_char_p))
        def collect(_, n, values, names):
            rows.append({names[i].decode(): values[i].decode('utf-8', 'replace')
                         if values[i] is not None else None for i in range(n)})
            return 0
        callback = callback_type(collect)
        rc = self.lib.sqlite3_exec(self.ptr, sql.encode(), callback, None, None)
        if rc:
            # No raw SQL or native error strings, since those may reveal secrets/content.
            raise RuntimeError(f'SQLCipher query failed (code {rc})')
        return rows

    def close(self):
        if self.ptr:
            self.lib.sqlite3_close(self.ptr)
            self.ptr = C.c_void_p()

    def __enter__(self):
        return self

    def __exit__(self, *args):
        self.close()


def load_key(path, db_path):
    p = Path(path)
    if p.stat().st_mode & 0o077:
        raise RuntimeError('key file must be private (chmod 600)')
    data = json.loads(p.read_text())
    if isinstance(data, dict) and isinstance(data.get('keys'), dict):
        data = data['keys']
    if not isinstance(data, dict):
        raise RuntimeError('key manifest must be an object')
    target = Path(db_path).resolve()
    with target.open('rb') as f:
        salt = f.read(16).hex()
    entries = []
    for name, value in data.items():
        normalized = name.replace('\\', '/')
        absolute_match = normalized.startswith('/') and Path(normalized).resolve() == target
        if normalized == salt or str(target).endswith('/' + normalized) or absolute_match:
            if isinstance(value, dict):
                value = value.get('enc_key', value.get('key'))
            if isinstance(value, str) and re.fullmatch('[0-9a-fA-F]{64}', value):
                entries.append(value.lower())
    if len(set(entries)) != 1:
        raise RuntimeError('missing or ambiguous key for this database')
    return entries[0]


import argparse
import collections
import csv
import hashlib
import json
import os
import re
import shutil
import subprocess
import sys
import tempfile
from datetime import date, datetime, time, timedelta
from pathlib import Path
from zoneinfo import ZoneInfo


def quote(value):
    return "'" + str(value).replace("'", "''") + "'"


def required_databases(root):
    return sorted([*(root / "contact").glob("contact.db"),
                   *[p for p in (root / "message").glob("message_*.db")
                     if re.fullmatch(r"message_\d+\.db", p.name)],
                   *[p for p in (root / "message").glob("media_*.db")
                     if re.fullmatch(r"media_\d+\.db", p.name)]])


def private_write(path, value):
    path.parent.mkdir(parents=True, exist_ok=True, mode=0o700)
    fd, tmp = tempfile.mkstemp(prefix=".write-", dir=path.parent)
    try:
        with os.fdopen(fd, "w") as f:
            json.dump(value, f, ensure_ascii=False, indent=2)
        os.replace(tmp, path)
    finally:
        if os.path.exists(tmp):
            os.unlink(tmp)


class Reader:
    def __init__(self, root, keyfile):
        self.root, self.keyfile = Path(root), Path(keyfile)

    def open(self, path):
        try:
            key = load_key(self.keyfile, path)
            return DB(path, key)
        except (RuntimeError, OSError, ValueError) as e:
            raise ValueError("Cannot read " + str(path.relative_to(self.root)) +
                             ". Supply a verified key manifest for this database; original error: " + str(e)) from e

    def contacts(self, query):
        with self.open(self.root / "contact/contact.db") as db:
            rows = db.query("SELECT username,alias,remark,nick_name FROM contact")
        needle = query.casefold()
        return [r for r in rows if not (r["username"] or "").endswith("@chatroom")
                and any(needle in (r[k] or "").casefold()
                        for k in ("username", "alias", "remark", "nick_name"))]

    def resolve(self, query):
        matches = self.contacts(query)
        exact = [r for r in matches if any((r[k] or "").casefold() == query.casefold()
                 for k in ("username", "alias", "remark", "nick_name"))]
        if len(exact) != 1:
            raise ValueError("Contact is absent or ambiguous. Run contacts and use the exact username.")
        return exact[0]

    def voices(self, contact, direction="received", since=None, until=None, timezone="Asia/Shanghai"):
        user = contact["username"]
        tz = ZoneInfo(timezone)
        lo = int(datetime.combine(date.fromisoformat(since), time.min, tz).timestamp()) if since else None
        hi = int(datetime.combine(date.fromisoformat(until) + timedelta(days=1), time.min, tz).timestamp()) if until else None
        if lo is not None and hi is not None and lo >= hi:
            raise ValueError("--since must not be later than --until")
        table = "Msg_" + hashlib.md5(user.encode()).hexdigest()
        messages = {}
        shards = [p for p in required_databases(self.root) if re.fullmatch(r"message_\d+\.db", p.name)]
        if not shards:
            raise ValueError("No local message shards found")
        for path in shards:
            with self.open(path) as db:
                if not db.query("SELECT name FROM sqlite_master WHERE name=" + quote(table)):
                    continue
                rows = db.query("SELECT m.local_id,m.server_id,m.create_time,n.user_name AS sender "
                                "FROM " + table + " m LEFT JOIN Name2Id n ON n.rowid=m.real_sender_id "
                                "WHERE (m.local_type & 4294967295)=34")
            for row in rows:
                received = row["sender"] == user
                if direction == "received" and not received:
                    continue
                if direction == "sent" and (received or row["sender"] is None):
                    continue
                timestamp = int(row["create_time"])
                if (lo is not None and timestamp < lo) or (hi is not None and timestamp >= hi):
                    continue
                sid = str(row["server_id"] or "0")
                ident = sid if sid != "0" else path.name + ":" + row["local_id"]
                record = dict(message_id=sid, local_id=row["local_id"], timestamp=timestamp,
                              sent_at=datetime.fromtimestamp(timestamp, tz).isoformat(),
                              direction="received" if received else ("sent" if row["sender"] else "unknown"),
                              message_database=path.name)
                if ident in messages and any(messages[ident][k] != record[k]
                                             for k in ("timestamp", "direction")):
                    raise ValueError("Conflicting message records for server ID " + sid)
                messages.setdefault(ident, record)
        media = collections.defaultdict(list)
        for path in required_databases(self.root):
            if not re.fullmatch(r"media_\d+\.db", path.name):
                continue
            with self.open(path) as db:
                rows = db.query("SELECT v.rowid AS media_rowid,v.svr_id,length(v.voice_data) AS bytes "
                                "FROM VoiceInfo v JOIN Name2Id n ON n.rowid=v.chat_name_id "
                                "WHERE n.user_name=" + quote(user))
            for row in rows:
                if row["svr_id"] and row["svr_id"] != "0" and int(row["bytes"] or "0") > 0:
                    media[row["svr_id"]].append((path.name, row["media_rowid"], int(row["bytes"])))
        result = []
        for record in messages.values():
            matches = media.get(record["message_id"], [])
            record["available"] = len(matches) == 1
            record["status"] = "available" if len(matches) == 1 else ("not_local" if not matches else "ambiguous_audio")
            record["audio_bytes"] = matches[0][2] if len(matches) == 1 else None
            record["_audio"] = matches[0] if len(matches) == 1 else None
            result.append(record)
        return sorted(result, key=lambda r: (r["timestamp"], r["message_id"]))

    def audio(self, record, user):
        shard, rowid, size = record["_audio"]
        with self.open(self.root / "message" / shard) as db:
            rows = db.query("SELECT hex(v.voice_data) AS body FROM VoiceInfo v "
                            "JOIN Name2Id n ON n.rowid=v.chat_name_id WHERE v.rowid=" + str(int(rowid)) +
                            " AND v.svr_id=" + str(int(record["message_id"])) +
                            " AND n.user_name=" + quote(user))
        if len(rows) != 1:
            raise ValueError("Audio changed since listing; rerun the command")
        data = bytes.fromhex(rows[0]["body"])
        if len(data) != size or not data.startswith((b"#!SILK_V3", b"\x02#!SILK_V3")):
            raise ValueError("Audio is incomplete or not recognised SILK")
        return data


def public(record):
    return {k: v for k, v in record.items() if not k.startswith("_")}


def export(reader, contact, rows, output, timezone, keep_silk=False):
    import pilk
    ffmpeg, ffprobe = shutil.which("ffmpeg"), shutil.which("ffprobe")
    if not ffmpeg or not ffprobe:
        raise ValueError("Install ffmpeg and ffprobe (brew install ffmpeg)")
    if not any(r["available"] for r in rows):
        raise ValueError("No unambiguous local audio to export")
    output = Path(output).expanduser().resolve()
    output.mkdir(parents=True, exist_ok=False, mode=0o700)
    counts = collections.Counter(r["timestamp"] for r in rows if r["available"])
    manifest = {"contact": contact["username"], "timezone": timezone,
                "source": "Local WeChat chat/media databases; no favourites or playback recovery",
                "records": []}
    private_write(output / "manifest.json", manifest)
    for row in rows:
        item = public(row)
        if row["available"]:
            data = reader.audio(row, contact["username"])
            stamp = datetime.fromtimestamp(row["timestamp"], ZoneInfo(timezone)).strftime("%Y-%m-%d_%H-%M-%S")
            if counts[row["timestamp"]] > 1:
                stamp += "_" + row["message_id"]
            mp3 = output / (stamp + ".mp3")
            with tempfile.TemporaryDirectory(prefix="wechat-voice-") as tmp:
                silk, pcm = Path(tmp) / "voice.silk", Path(tmp) / "voice.pcm"
                silk.write_bytes(data)
                pilk.decode(str(silk), str(pcm), pcm_rate=24000)
                if pcm.stat().st_size == 0 or pcm.stat().st_size % 2:
                    raise ValueError("Decoder produced empty or invalid PCM")
                decoded = pcm.stat().st_size / 48000
                subprocess.run([ffmpeg, "-v", "error", "-nostdin", "-n", "-f", "s16le",
                                "-ar", "24000", "-ac", "1", "-i", str(pcm),
                                "-c:a", "libmp3lame", "-q:a", "2", str(mp3)], check=True)
            subprocess.run([ffmpeg, "-v", "error", "-nostdin", "-i", str(mp3),
                            "-f", "null", "-"], check=True)
            probe = json.loads(subprocess.check_output([ffprobe, "-v", "error", "-show_entries",
                                "format=duration:stream=codec_name", "-of", "json", str(mp3)], text=True))
            if not probe["streams"] or probe["streams"][0]["codec_name"] != "mp3":
                raise ValueError("Output is not MP3")
            duration = float(probe["format"]["duration"])
            if abs(duration - decoded) > 0.25:
                raise ValueError("MP3 duration differs unexpectedly from decoded audio")
            if keep_silk:
                (output / (stamp + ".silk")).write_bytes(data)
            item.update(filename=mp3.name, decoded_seconds=decoded, mp3_seconds=duration,
                        silk_sha256=hashlib.sha256(data).hexdigest(),
                        mp3_sha256=hashlib.sha256(mp3.read_bytes()).hexdigest(),
                        status="exported")
        manifest["records"].append(item)
        private_write(output / "manifest.json", manifest)
    fields = sorted(set().union(*(r.keys() for r in manifest["records"])))
    with (output / "manifest.csv").open("w", newline="") as f:
        writer = csv.DictWriter(f, fieldnames=fields)
        writer.writeheader()
        writer.writerows(manifest["records"])
    return {"output": str(output),
            "exported": sum(r["status"] == "exported" for r in manifest["records"]),
            "skipped": sum(r["status"] != "exported" for r in manifest["records"])}


def main():
    os.umask(0o077)
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--db-root", type=Path, required=True)
    parser.add_argument("--key-file", type=Path, required=True)
    parser.add_argument("--contact", required=True, help="Exact username, nickname, remark or alias")
    parser.add_argument("--since")
    parser.add_argument("--until")
    parser.add_argument("--timezone", default="Asia/Shanghai")
    parser.add_argument("--direction", choices=("received", "sent", "both"), default="received")
    parser.add_argument("--output", help="Export into this NEW directory; omit to list")
    parser.add_argument("--keep-silk", action="store_true")
    args = parser.parse_args()
    root = args.db_root.expanduser().resolve()
    reader = Reader(root, args.key_file.expanduser().resolve())

        print(json.dumps(result, ensure_ascii=False, indent=2))
    except (ValueError, RuntimeError, OSError, subprocess.SubprocessError, ImportError) as error:
        parser.exit(1, "Error: " + str(error) + "\n")


if __name__ == "__main__":
